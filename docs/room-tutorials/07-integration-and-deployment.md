# 集成与部署

Room MCP Kit 默认用于单机或可信局域环境。先跑通本地版本，再决定是否放到公网。

## 进程

- 静态网页与同源 REST 网关；
- Room REST 服务；
- Room MCP 服务；
- 一个共享 SQLite 文件。

REST 与 MCP 可以作为两个进程共享同一数据库。浏览器不应直接得到服务端 Room Token；由同源网关代为注入。

## 自托管检查

- 使用 HTTPS 提供网页；
- 只公开网页所需的 `owner` REST 路由和只读状态/SSE；
- MCP 默认监听回环地址；需要远程 MCP 时由使用者自行放到可信隧道或认证代理后；
- `.env`、SQLite、日志和自定义私人人物包不提交到 Git；
- 静态资源路径返回 200，Canvas 启动后控制台无错误。

公共仓库不附带特定 VPS、域名、聊天系统或整站发布脚本。部署适配应保存在使用者自己的私有配置中。

## 发布顺序

1. 运行全部测试；
2. 本地验证 Room、校准页、移动、家具交互和布局保存；
3. 检查仓库没有私人人物、绝对素材路径、Token 或数据库；
4. 构建不可变版本或 tag；
5. 部署并直接验证页面、REST health 和 MCP 工具。
