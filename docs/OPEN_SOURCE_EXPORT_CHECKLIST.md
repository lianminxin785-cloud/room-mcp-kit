# room-mcp-kit 开源导出清单

更新日期：2026-08-24

本文档是 `room-mcp-kit` 的公共导出边界和发布前清单。它优先保护私人人物资产，同时保证公共版最终可以独立运行、校准和接入 MCP。

## 1. 已确定的产品边界

- [x] 公共项目名使用 `room-mcp-kit`。
- [x] 建立全新本地 Git 仓库，不继承私有项目的 Git 历史。
- [x] 默认前端采用本地调试版的宽屏 `16:9` Room 视口。
- [x] 保留手机触控与响应式布局，但不复制私有项目的手机 Chat 外壳。
- [x] 房间世界、地图、家具、角色和状态服务可独立运行。
- [x] 使用者在网页控制 `owner`，AI 通过 MCP 控制 `companion`。
- [x] 角色显示名称从配置读取，不写死任何私人姓名。
- [x] 场景使用稳定的 `scene_id`，第一版默认场景为 `home`。

## 2. MCP 公共接口

公共版只保留四个通用工具：

- [x] `room_get_state`：读取场景、人物、家具、语义区域和当前动作。
- [x] `room_move`：让 `companion` 移动到坐标、语义区域或家具附近。
- [x] `room_use_furniture`：通过 `furniture_id + interaction` 使用任意家具。
- [x] `room_stop`：停止移动或当前家具动作。

约束：

- [x] MCP 只能直接控制 `companion`。
- [x] 网页 API 只能直接控制 `owner`。
- [x] 不为床、沙发、书架等家具分别创建工具。
- [x] “工作”和“一起工作”等状态保持为不同活动状态。
- [x] 两人使用同一家具时仍各占不同槽位；需要固定角色槽位的家具不得自动互换。

### 4.1 私人人物资源

以下来源及其任何转换、裁切、像素化或运行副本都不得公开：

```text

web/room/assets/room-v2/source/manual/characters/**
web/room/assets/room-v2/source/person/**
web/room/assets/room-v2/source/clean/person/**
web/room/assets/room-v2/source/duo/**

```

看书等后续新增的人物动作素材同样不得公开。人物原图、行走帧、待机帧、动作帧、换装图、双人合成图、校准中间图和最终图均视为同一私有资产边界。

### 4.2 私有产品耦合

公共版不导出：

```text

web/config.js
web/sw.js
deploy/stage13-room/**
私有交接文档与实施计划

```

公共版也不得包含：

- 私人 Chat 会话、消息、语音或状态数据库。
- API 密钥、Token、Cookie、域名、VPS 地址和 `.env` 实值。
- 私人 Profile、人设提示词、日历数据或其他私有项目页面。
- 私有项目的发布脚本、服务器目录和 Service Worker 缓存版本。
