# 美术素材指南

公开示例背景和家具可以直接用于演示；自定义项目可以替换为自己的素材。

## 制作原则

- 背景按照 `1600×1600`、1:1 世界构图；屏幕只显示其中一个宽屏区域。
- 家具和人物使用透明 PNG，主体完整、边缘干净、不贴画布。
- 同一人物所有方向、动作和服装保持轮廓比例一致。
- 手工确认的母版进入 `source/manual/**`；处理结果进入 `game/**`。
- 像素人物和家具只使用 NEAREST 缩放；背景是否使用 NEAREST 取决于原始画风。

生成式美术的使用者应自行确认所用平台的输出条款，并在 `ASSET_PROVENANCE.md` 记录模型、是否使用参考图以及人工裁切、透明化、分层和校准过程。

不要把私人人物或未获授权的第三方角色放入公开仓库。教程可以公开流程，但不会自动授予输入素材的版权或许可。
