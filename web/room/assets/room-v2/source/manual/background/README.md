# Room v2 方形背景图规范

这份文件是正式 Room 背景的唯一尺寸契约。背景世界是方形；桌面地图框保持 `16:9`，竖屏手机
页面为 `9:16`，Canvas 使用固定 UI 以外的剩余高度。两种布局都只显示世界局部，不把整张方形背景
压缩进屏幕。

## 最终交付尺寸

```text
像素尺寸：1600 × 1600 px
长宽比：  1:1
逻辑世界：1600 × 1600
逻辑网格：100 × 100（每格 16px）
格式：    PNG，RGB 或不透明 RGBA
```

当前源图 `background.png` 作为保留母版，由
`tools/process_room_background_assets.py` 一次性使用 Lanczos 生成 `1600 × 1600` 运行图。
运行时一张图对应同尺寸世界坐标，不做非等比拉伸。

## 画面内容边界

- 背景只画不可移动的建筑部分：墙、地板、窗、门、踢脚线和固定墙面装饰。
- 不把床、沙发、工位、电视、地毯、人物、宠物或可拾取摆件烘焙进背景。
- 外圈保留至少 `64px` 的建筑安全边界；重要门窗与固定结构不要贴着裁切边。
- 地板必须形成连续可通行区域，不用地板纹理绘制假的实体台阶、柜体或大面积障碍。
- 光源和透视方向需全图统一；家具仍由独立透明图层负责遮挡和碰撞。

## 视口与相机契约

桌面地图框保持 `16:9`，相机 100% 时横向约显示 `1280px` 世界；竖屏手机页面固定为 `100dvh`，
Canvas 铺满标题、控制栏和人物状态卡之外的剩余区域，相机 100% 时横向约显示 `720px` 世界。
Phaser 画布随父容器 resize，不用黑边补成横屏比例。鼠标或单指拖动平移，滚轮或双指捏合缩放，
并把相机限制在 `1600 × 1600` 世界边界内。底部水平滑块辅助左右浏览；短点击地面用于人物移动，
只有超过 `12px` 拖动阈值才移动镜头。
